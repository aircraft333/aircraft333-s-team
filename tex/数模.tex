\begin{abstract}
    随着“双碳”目标的推进和微网系统的快速发展，微网系统的经济调度成为促进新能源就地消纳、降低用能成本的关键。为此，本文在分时电价机制下，基于给定的电价、小区负载、光伏发电预测等数据，建立数学模型，协调外部电网购电和储能设备充放电，以实现经济效益最大化。\newline \hspace*{2em}
    针对问题一，本文首先对电价、小区负载、光伏发电预测等数据进行了可视化分析，为进一步建模提供支撑。在所有变量完全已知的情况下，确认这是一个确定性优化问题，结合6个约束条件，建立以\textbf{全天费用最小}为目标函数的\textbf{线性规划（LP）模型}。求解得到全天各时段的计划购电量与储能充放电调度方案。得到全天总购电量为\textbf{59482.6990 kWh},全天总购电费为\textbf{35126.9486 元}。\newline \hspace*{2em} 针对问题二，本文首先通过读取附件2的全年负载绘制每周同一天的小区负载曲线叠加图和ACF图，发现小区负载具有周期性；接着，通过“前三天滑动平均”预测光伏发电。建立\textbf{二阶段线性规划模型}：第一阶段根据小区负载和光伏发电功率预测值，引入\textbf{报童模型}计算出紧急购电量，求出初步的购电策略；第二阶段模拟实际运行,触发紧急购电惩罚，采用\textbf{逐槽法}得到全年购电策略，并计算出全年购电费用13,949,108.5 元,全年购电量为21584237.4kWh.

        \end{abstract}
        \section{问题重述}
        \subsection{问题背景}
       随着“碳达峰、碳中和”目标的推进，以光伏为代表的分布式能源正经历跨越式发展。微网能解决大规模并网带来的反向潮流、电压波动等问题，成为新型电力系统的发展趋势。而外网普遍实行峰谷分时电价机制，电价在不同时段存在显著差异。为了满足小区的负载且节省微网的购电费用，建立数学模型制定合理的购电策略和储能设备的充放电量尤为重要。
        \subsection{问题重述}
        \noindent\textbf{问题一:}
        \begin{itemize}
            \item 假设每天电价与小区负载固定。
            \item 要求微网提供的电能不可低于小区负载，且储能设备在 0:00 和 24:00 的储电量相同。
            \item 根据光伏发电功率一天的预测数据，给出每天 0:00 制定微网当天的计划购电策略的数学模型。
        \end{itemize}
        
        \noindent\textbf{问题二:}
        \begin{itemize}
        \item 假设每天电价恒定，但小区负载与光伏发电功率随时间波动。
        \item 要求若计划供电量低于实际负载需以5倍实时电价紧急购电；常规时段购电仍按计划购电量计费。
        \item 给出每天
0:00 制定微网当天的计划购电策略。
\end{itemize}
        \noindent\textbf{问题三:}
        \begin{itemize}
        \item 假设每天0:00、6:00、12:00 和 18:00 可获得未来 24 小时整点的光伏发电功率预报，允许每天滚动调整购电策略。
        \item 要求：计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50\%；调整购电量高于计划购电量的部分，超出部分的电价按交易时刻电价的 1.5 倍支付。总的购电费用包括计划购电费用、紧急购电费用和调整购电量的相关费用。
        \item 建立微网当天购电策略的数学模型
        \end{itemize}
        \noindent\textbf{问题四:}
        针对外网电价实时波动，建立微网当天购电策略的数学模型。
       \section{问题分析}
        \subsection{问题一的分析}
        问题一要求在每天 0:00 制定微网当天的计划购电策略的数学模型。具体条件为每天电价与小区负载固定，满足微网提供的电能不可低于小区负载，且储能设备在 0:00 和 24:00 的储电量相同的需求。由于所有输入数据均为已知常量，故该问题为一个确定性优化问题。可以通过数学方法算出最小值，且所有约束条件均可转化为线性等式或不等式，故选择线性规划(LP)模型。求解时，通过Python的PuLP库构建模型，调用CBC求解器，求出全局最优解。
    \subsection{问题二的分析}

    \subsection{约束条件}
    模型需满足以下约束：
    \begin{enumerate}
        \item 微网电力供需平衡约束：
        \[
        P_{buy,t}+P_{pv,t}+P_{dis,t}-P_{ch,t}-P_{curt,t} \ge L_t,
        \qquad t=1,2,\ldots,T.
        \]
        \item 储能电池状态转移方程：需要引入储能设备的荷电状态，建立相邻时间段储能电量与充放电量递推关系，
        \[
        E_t = E_{t-1}+\eta_{ch}\cdot P_{ch,t}\Delta t-\frac{P_{dis,t}}{\eta_{dis}} \cdot \Delta t,
        \qquad t=1,2,\ldots,T.
        \]
        \item 储能荷电状态（SOC）安全上下限：\[E_{min}\leqslant E_t\leqslant E_{max}  \qquad t=1,2,\ldots,T.\]
        \item 储能始末电量守恒约束:要求储能设备在0:00和24:00的储电量相同，
        \[
        E_0=E_T=6000\,\text{kWh}
        \]
        \item 充放电功率上下限互斥约束:储能设备在任意时段的充放电功率不能超过其额定的最大充放电功率，
        \[
        0\leqslant P_{ch,t}\leqslant u_t\cdot P_{max},\qquad
        0\leqslant P_{dis,t}\leqslant (1-u_t)\cdot P_{max},\qquad
        u_t\in\{0,1\}.\qquad t=1,2,\ldots,T.
        \]
        \item 购电非负性约束:
        仅考虑微网向外网单向购电，
        \[
        P_{buy,t}\ge 0,\qquad P_{curt,t}\ge 0,\qquad t=1,2,\ldots,T.
        \]
        \end{enumerate}
    \subsection{模型求解}
     考虑到经济效益，为使全天购电总费用（Z）最小，目标函数为：
     \begin{equation}
     min \mathbf{Z} =\sum_{t= 1}^{T} c_t\cdot (P_{buy,t}\cdot \Delta t) 
     \end{equation}
将所需变量代入线性规划模型（见附录）中，在约束条件下使得目标函数的值最小，得到当天购电策略如表1、表2。

        \section{问题二模型的建立与求解} 
        \subsection{模型建立}
        问题二的电价每日恒定，但小区负载和光伏发电功率具有随机波动性。且若实际供电量低于小区负载需求，需承担高达5倍实时电价的紧急购电惩罚。因此这属于不确定性优化问题。为规避巨额惩罚风险，本节引入两阶段线性规划模型并结合报童型安全裕量，构建兼顾经济性与可靠性的购电策略优化模型。

        设第 \(d\) 天、第 \(t\) 个时段（\(t=1,\ldots,144\)）的负荷为 \(L_{d,t}\)，则日前预测值为 \(\hat{L}_{d,t}\)为：\newline
\begin{equation}
\hat{L}_{d,t} = 
\begin{cases}
L_{d-7,t}^{\text{real}}, & d \ge 7 \\
L_{\text{att1},t}, & d < 7 \quad (\text{前7天无历史周数据时，用附件1基准日代替})
\end{cases}
\end{equation}

        \par\textbf{（2）光伏发电功率预测：} 由于光伏发电受到天气因素影响，随时间波动，本文采用“前3天滑动平均”方法，计算得到光伏预测发电功率。设第 $d$ 天第 $t$ 时段的实际光伏为 $G_{d,t}^{\text{real}}$，滑动窗口 $k=3$：
\begin{equation}
\hat{G}_{d,t} =
\begin{cases}
\dfrac{1}{\min(d,3)}\sum_{j=1}^{\min(d,3)} G_{d-j,t}^{\text{real}}, & d \ge 1,\\[4pt]
G_{\text{att1},t}, & d = 0.
\end{cases}
\end{equation}
\subsubsection{报童模型}
设第 $d$ 天第 $t$ 时段的预测净负荷为
\[
Net_{d,t}^{\mathrm{pred}} = \hat{L}_{d,t} - \hat{G}_{d,t},
\]
其中 $\hat{L}_{d,t}$ 和 $\hat{G}_{d,t}$ 分别为负荷与光伏发电功率的预测值。由于预测不可避免地存在误差，若计划购电量等于 $Net_{d,t}^{\mathrm{pred}}$，则在实际净负荷大于预测值时会产生少购电惩罚；而少购电的惩罚远大于多购电的成本，因此引入报童模型来设置安全裕量。\newline\hspace*{2em} 设超额边际（多购电）成本为 $c_o$，欠额边际（少购电）损失为 $c_u$：
\begin{itemize}
    \item $c_o = \pi_t$
    \item $c_u = 5\pi_t - \pi_t = 4\pi_t$
\end{itemize}

根据运筹学经典\textbf{报童临界分位数公式}，最优购电量临界分位数 $\alpha^*$ 满足：
\begin{equation}
\alpha^* = \frac{c_u}{c_u + c_o} = \frac{4\pi_t}{4\pi_t + \pi_t} = \frac{4}{5} = 0.80 \ (80\%)
\end{equation}
即计划购电量覆盖历史预测误差的 80\% 分位数作为当天该时段的安全裕量，此时期望总成本最低\cite{ref1}。
历史同一时段的预测误差样本集合为：
\begin{equation}
\varepsilon_{j,t} = (L_{j,t}^{\text{real}} - G_{j,t}^{\text{real}}) - (\hat{L}_{j,t} - \hat{G}_{j,t})
\end{equation}
取过去窗口期 $W$ 天的数据（保证边界大于等于 0），从过去 $W$ 天误差样本中找到第 80 百分位数，赋给 $X_{d,t}$：
\begin{equation}
X_{d,t} = \mathrm{Quantile}_{\alpha^*}\left(\left\{\varepsilon_{j,t}\mid \max(0,d-W)\le j<d\right\}\right).
\end{equation}
得到最终等效预测负荷为\begin{equation}
\tilde{L}_{d,t} = \hat{L}_{d,t} + X_{d,t}
\end{equation}
\subsubsection{两阶段优化模型}
本模型分为两个阶段：第一阶段
日前0:00单日线性规划；
第二阶段模拟实际运行，触发紧急购电惩罚。
\subsubsection{决策变量的确定}
本节设定以下五个决策变量：
\begin{enumerate}
    \item \textbf{$b_t \geqslant 0$},其中 $b_t$是第t时段计划购电功率
    \item \textbf{$c_t\geqslant 0$},$c_t$是第t时段计划储能充电功率
    \item \textbf{$d_t \geqslant 0$},其中 $d_t$是第t时段计划购储能放电功率
    \item  若中午光伏供电功率大且储能电池已充满，多余的电能无处消纳，会导致功率平衡方程无解，故引入弃光功率 \newline
    \hspace*{2em} \textbf{$s_t \geqslant 0$},其中 $s_t$是第t时段计划弃光功率
    \item \textbf{$E_t$}：$E_t$ 是第 $t$ 时段末储能状态电量 \newline  \hspace*{2em}由于储能充放电存在效率损耗（$\eta=0.95<1$），同时充放电（$c_t>0,d_t>0$）会导致 $\eta^2=0.9025$ 的净能量损耗，在线性规划求解极小值时，最优解天然满足互斥条件 $c_t\cdot d_t=0$，因此可以直接使用连续变量 LP 求解，提升了计算速度。
\end{enumerate}
        \subsection{约束条件}
        本模型需满足以下约束条件：
        \begin{enumerate}
    \item \textbf{日前功率平衡约束：}题目要求任何时刻微网提供的总电能不会低于小区负载，
    \begin{equation}
        b_t + \hat{G}_{d,t} + d_t - c_t - s_t \geqq  \tilde{L}_{d,t}, \quad \forall t = 1, \dots, 144
    \end{equation}
\item \textbf{储能动态容量演化与初值约束：}
    \begin{equation}
        E_t = E_{t-1} + \left( \eta \cdot c_t - \frac{d_t}{\eta} \right) \cdot \Delta t, \quad \forall t = 1, \dots, 144 \quad (\text{其中 } E_0 = E_d^{\text{start}})
    \end{equation}
\item \textbf{储能运行上下限约束：}将充放电功率和储电量约束在合理的物理范围内，
    \begin{align}
        & 0 \le c_t \le P_{\text{rate}} \quad (5000\text{ kW}) \\
        & 0 \le d_t \le P_{\text{rate}} \quad (5000\text{ kW}) \\
        & E_{\min} \le E_t \le E_{\max} \quad (1200\text{ kWh} \le E_t \le 10800\text{ kWh})
    \end{align}
\item \textbf{非负性：} 不考虑微网向外网售电，\newline  \hspace*{2em}$b_t \ge 0, s_t \ge 0$。
\end{enumerate}
    \subsection{模型求解}
    \textbf{(a) 第一阶段线性规划求解} \newline  \hspace*{2em}
为提高经济效益，目标函数确定为最小化单日计划购电费用：
\[
\min \sum_{t=1}^{144} \pi_t \cdot b_t \cdot \Delta t
\] 其中，$\pi_t$ 为 $t$ 时段的电价，$\Delta t=10\,\text{min}$。\\
\hspace*{2em}
引入报童模型，通过CBC求解器求解，得到当日初步的购电计划和全天最小的计划购电费用（见附录）。\newline  \hspace*{2em}
\textbf{(b) 第二阶段紧急购电与实际执行} \newline  \hspace*{2em}
进入时段t,实际负荷与实际光伏发电功率出现波动，会与预测值产生实时净偏差：
\[
\Delta P_t = L_t^{\text{real}} - G_t^{\text{real}} - b_t
\]
由于只能观测当前偏差$P_t$，采用逐槽法做出当前最优动作： 
（1）若 $\Delta P_t>0$，存在电力缺口。
先利用先前储能进行放电，放电过程受到放电最大功率 $P_{\max}$ 和当前剩余可用电量 $(E_{t-1}-E_{\min})$ 的双约束：
\[
d_t = \min \left( \Delta P_t,\, P_{\max},\, \frac{(E_{t-1} - E_{\min}) \cdot \eta}{\Delta t} \right)
\]
如果储存电量不足以弥补电力缺口，则触发紧急购电：
\[
e_t = \Delta P_t - d_t
\]
（2）	若deltaP<0,电力过剩
将富余的电能冲进储能电池储存起来，留给以后缺电的时候用。
所冲电功率：
\[
c_t = \min \left( -\Delta P_t,\, P_{\max},\, \frac{(E_{\max} - E_{t-1})}{\eta \cdot \Delta t} \right)
\]
如果以及超过电池储能上限，则进行无损耗弃电。弃电功率：
\[
s_t = -\Delta P_t - c_t
\]
逐槽状态变化：
\[
E_t = E_{t-1} + \left( \eta c_t - \frac{d_t}{\eta} \right) \Delta t
\]
更新后的 $E_t$ 作为下一个时段 $t+1$ 的初始状态，依次推进至 $t=143=24\times60/10-1$。得到考虑紧急购电的完整购电策略，并得到全年购电费用13,949,108.5 元（计划 21,442,248.8 kWh / 1,315.5 万 + 紧急 141,988.6 kWh / 79.4 万；其中紧急天数共 141/334天。

\section{问题三模型的建立与求解}
        \subsection{模型建立}
        由于光伏发电功率预报在不断更新，且存在双向偏差惩罚，为了在二者之间寻找平衡，在第二问的基础上建立多阶段滚动调整线性优化模型，整体分为三个阶段。
       \subsubsection{不确定性因素的定义与预测}
        问题三与问题二最大的不同在于光伏发电功率能不断更新，而小区负载和光伏发电功率仍随时间波动，因此小区负载预测和光伏发电功率预测同第二问。
        \subsubsection{报童模型}
与第二问不同，第三问只要改变计划量就会产生惩罚，是典型的非对称不确定性损失。少买电的惩罚（$5\pi_t$）远大于多买电的成本（$\pi_t$），设超额边际成本为 $c_o$，欠额边际损失为 $c_u$:\newline \hspace*{2em}\textbf{(a)计划阶段（0:00）：}多买 1 kWh 的成本是 $\pi_t$，少买 1 kWh 则要按 $5\pi_t$ 紧急购电：
\begin{equation}
c_{o} = \pi_{t},\qquad c_{u} = 5\pi_{t} - \pi_{t} = 4\pi_{t}
\end{equation}
\begin{equation}
\alpha^{*} = \frac{c_u}{c_u + c_o} = \frac{4}{5} = 0.80
\end{equation}
\newline \hspace*{2em}\textbf{(b)调整阶段（6:00 / 12:00 / 18:00）：}调整电价规则改变了两侧的边际成本：超出计划的部分单价为 $1.5\pi_t$，少买的部分只退 $0.5\pi_t$。因此：
\begin{equation}
    c_o = 1.5\pi_t,\qquad c_u = 5\pi_t - 1.5\pi_t = 3.5\pi_t
\end{equation}
\begin{equation}
    \alpha^{*} = \frac{c_u}{c_u + c_o} = \frac{3.5}{5} = 0.70
\end{equation}
两个阶段的临界分位比并不相同，而两阶段共用同一个裕量，故最优裕量应落在 $[0.70, 0.80]$ 区间内，取中点 $\alpha^*=0.75$。历史误差样本取的是“负载预报误差”。问题三的光伏已由附件3承担，故裕量只加在负载侧，不重复计入。
\begin{equation}
\varepsilon_{j,t} = L^{\mathrm{real}}_{j,t} - \hat{L}_{j,t}
\end{equation}
从过去 $W$ 天的误差样本中取 $\alpha^*$ 分位数，即为该时段的裕量 $X$（回看窗口 $W=60$ 天，且严格只用当日之前的数据）：
\begin{equation}
X_{d,t} = \mathrm{Quantile}_{\alpha^{*}}\!\left(\left\{\varepsilon_{j,t}\ \middle|\ \max(0,\,d-W) \le j < d\right\}\right)
\end{equation}
$X_{d,t}$ 即为裕量。最终等效预测负荷：
\begin{equation}
\tilde{L}_{d,t} = \hat{L}_{d,t} + X_{d,t}
\end{equation}

        \section{问题四模型的建立与求解}
        \subsection{模型建立}
        问题四紧承问题二三，在前两问的基础上增加了波动但完全已知的外网电价。在我们的求解模型中，并未加入新的决策机制，而是将前两问的模型整体搬到电价不再固定的环境下，证明了其适应性与经济性。直接套用模型这一做法的合理性将在后文做出证明。
        分析附件四的电价数据特征：
        \begin{itemize}
            \item 整体形状与附件一中电价逐时段一一对应，且列均值恒等于附件1 的电价，最大绝对差仅 5.2e-5
            \item 逐日均价在 0.5378 ~ 0.9290 之间漂移（标准差 0.1036），最高日与最低日相差 73%
            \item 日内峰谷比均值 5.74，而附件1 固定电价下为 3.76
        \end{itemize}
        由此可以确认附件4 的生成结构：电价 = 附件1 的分时形状 + 逐日整体水平漂移 + 逐槽噪声：
        \[
            \frac{1}{365}\sum_{d=1}^{365}\pi_{d,t} \equiv \pi^{\mathrm{att1}}_t \qquad \left(\max_t |\cdot| = 5.2\times 10^{-5}\right)
        \]

        \[
            \mathrm{R}_d = \frac{\max_t \pi_{d,t}}{\min_t \pi_{d,t}}, \qquad \overline{\mathrm{R}} = \frac{1}{365}\sum_{d}\mathrm{R}_d = 5.74
        \]

        这样的结构说明：首先，日内“谷充峰放”的套利空间依然存在，甚至比之前更大，因为峰谷比加大了。同时，出现了跨日套利空间，即在电价便宜的日期多充，在电价贵的日期多放。

        \subsubsection{对应问题二：0时线性规划与实时逐槽被动平衡}
        模型与问题二完全同构，只是把固定的 $\pi_t$ 换成逐日逐时段的 $\pi_{d,t}$。

        \noindent\textbf{(1)0时线性规划}

        决策变量：
        \begin{itemize}
            \item $b_t$：购电量
            \item $c_t$：充电
            \item $d_t$：放电
            \item $s_t$：弃光
            \item $E_t$：储电量
        \end{itemize}
        约束条件：
        与问题二一致地，
        \begin{itemize}
            \item 日前功率平衡
                  \[
                  b_t + \hat{G}_{d,t} + d_t - c_t - s_t = \tilde{L}_{d,t},\qquad \forall t = 1,\dots,144
                  \]
            \item 储能动态容量演化与初值、上下限、非负性（与问题二完全一致，不再在此列出）
        \end{itemize}
        目标函数：
        \[
        \min\ \sum_{t=1}^{144}\pi_{d,t}\cdot b_t\cdot\Delta t
        \]
        安全裕量：
        与问题二一致，逐时段取历史 30 天净负荷预测误差的 0.76 分位数。

        \noindent\textbf{(2)实时逐槽法}
        
        求解方式为逐日滚动，储电量逐日连续传递。采取贪心算法，与问题二完全一致。
        \subsubsection{对应问题三：四阶段滚动调整}
        模型与问题三完全同构，利用线性规划与逐槽法的融合，只是把固定的 $\pi_t$ 换成逐日逐时段的 $\pi_{d,t}$。购电费用变为
        \[
        C_t = \pi_{d,t}\min(b^{p}_t,\ b^{a}_t) + 0.5\pi_{d,t}\left(b^{p}_t - b^{a}_t\right)^{+} + 1.5\pi_{d,t}\left(b^{a}_t - b^{p}_t\right)^{+}
        \] 
        线性化方式保持不变
        \[
        b^a_t = b^p_t + δ⁺_t − δ⁻_t，C_t = π_{d,t}b^p_t + 1.5π_{d,t}δ⁺_t − 0.5π_{d,t}δ⁻_t
        \]
        利用目标函数的凸性与成本梯级差，将非线性分段规则天然松弛并精确嵌入纯线性规划中（在问题三已有证明）。
        滚动目标函数为
        \[
        \min\ \sum_{t=t_0}^{144}\left[\,C_t + 5\pi_{d,t}\,e_t\,\Delta t\,\right]
        \]
        其余口径与问题三一致
        \begin{itemize}
            \item 光伏预报取 40% 附件3 + 60% 前 3 天均值
            \item 负载预报为上周同一天叠加当日自适应修正（限幅 ±20%）
            \item 安全裕量为逐时段历史 60 天负载误差的 0.75 分位数
            \item 决策时刻 (0, 6, 12, 18)
        \end{itemize}
