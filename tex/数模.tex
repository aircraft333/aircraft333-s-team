\begin{abstract}
    随着“双碳”目标的推进和微网系统的快速发展，微网系统的经济调度成为促进新能源就地消纳、降低用能成本的关键。为此，本文在分时电价机制下，基于给定的电价、小区负载、光伏发电预测等数据，建立数学模型，协调外部电网购电和储能设备充放电，以实现经济效益最大化。\newline \hspace*{2em}
    针对问题一，本文首先对电价、小区负载、光伏发电预测等数据进行了可视化分析，为进一步建模提供支撑。在所有变量完全已知的情况下，确认这是一个确定性优化问题，结合6个约束条件，建立以\textbf{全天费用最小}为目标函数的\textbf{线性规划（LP）模型}。求解得到全天各时段的计划购电量与储能充放电调度方案。得到全天总购电量为\textbf{59482.6990 kWh},全天总购电费为\textbf{35126.9486 元}。\newline \hspace*{2em}

        \section{问题重述}
        \subsection{问题背景}
       随着“碳达峰、碳中和”目标的推进，以光伏为代表的分布式能源正经历跨越式发展。微网能解决大规模并网带来的反向潮流、电压波动等问题，成为新型电力系统的发展趋势。而外网普遍实行峰谷分时电价机制，电价在不同时段存在显著差异。为了满足小区的负载且节省微网的购电费用，建立数学模型制定合理的购电策略和储能设备的充放电量尤为重要。
        \subsection{问题重述}
        \quad\textbf{问题一:}
        \begin{itemize}
            \item 假设每天电价与小区负载固定。
            \item 要求微网提供的电能不可低于小区负载，且储能设备在 0:00 和 24:00 的储电量相同。
            \item 根据光伏发电功率一天的预测数据，给出每天 0:00 制定微网当天的计划购电策略的数学模型。
        \end{itemize}
        
        \quad\textbf{问题二:}
        \begin{itemize}
        \item 假设每天电价恒定，但小区负载与光伏发电功率随时间波动。
        \item 要求若计划供电量低于实际负载需以5倍实时电价紧急购电；常规时段购电仍按计划购电量计费。
        \item 给出每天
0:00 制定微网当天的计划购电策略。
\end{itemize}
        \quad\textbf{问题三:}
        \begin{itemize}
        \item 假设每天0:00、6:00、12:00 和 18:00 可获得未来 24 小时整点的光伏发电功率预报，允许每天滚动调整购电策略。
        \item 要求：计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50\%；调整购电量高于计划购电量的部分，超出部分的电价按交易时刻电价的 1.5 倍支付。总的购电费用包括计划购电费用、紧急购电费用和调整购电量的相关费用。
        \item 建立微网当天购电策略的数学模型
        \end{itemize}
        
        \quad\textbf{问题四:}
        针对外网电价实时波动，建立微网当天购电策略的数学模型。

    \subsection{约束条件}
    模型需满足以下约束：
    \begin{enumerate}
        \item 微网电力供需平衡约束：
        \[
        P_{buy,t}+P_{pv,t}+P_{dis,t}-P_{ch,t}-P_{curt,t} \ge L_t,
        \qquad t=1,2,\ldots,T.
        \]
        \item 储能电池状态转移方程：需要引入储能设备的荷电状态，建立相邻时间段储能电量与充放电量递推关系，
        \[
        E_t = E_{t-1}+\eta_{ch}\cdot P_{ch,t}\Delta t-\frac{P_{dis,t}}{\eta_{dis}} \cdot \Delta t,
        \qquad t=1,2,\ldots,T.
        \]
        \item 储能荷电状态（SOC）安全上下限：\[E_{min}\leqslant E_t\leqslant E_{max}  \qquad t=1,2,\ldots,T.\]
        \item 储能始末电量守恒约束:要求储能设备在0:00和24:00的储电量相同，
        \[
        E_0=E_T=6000\,\text{kWh}
        \]
        \item 充放电功率上下限互斥约束:储能设备在任意时段的充放电功率不能超过其额定的最大充放电功率，
        \[
        0\leqslant P_{ch,t}\leqslant u_t\cdot P_{max},\qquad
        0\leqslant P_{dis,t}\leqslant (1-u_t)\cdot P_{max},\qquad
        u_t\in\{0,1\}.\qquad t=1,2,\ldots,T.
        \]
        \item 购电非负性约束:
        仅考虑微网向外网单向购电，
        \[
        P_{buy,t}\ge 0,\qquad P_{curt,t}\ge 0,\qquad t=1,2,\ldots,T.
        \]
        \end{enumerate}
    
    \subsection{模型求解}
     考虑到经济效益，为使全天购电总费用最小，目标函数为：
     \begin{equation}
     min \mathbf{Z} =\sum_{t= 1}^{T} c_t\cdot (P_{buy,t}\cdot \Delta t) 
     \end{equation}

     将所需变量代入线性规划模型（见附录）中，在约束条件下使得目标函数的值最小，得到当天购电策略如表1、表2。
